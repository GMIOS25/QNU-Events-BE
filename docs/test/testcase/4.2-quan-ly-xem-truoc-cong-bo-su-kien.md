### 2.2. Phân tích giá trị biên (Boundary Value Analysis — BVA)

| Biến / Tham số & Ràng buộc trong Mã nguồn | Giá trị dưới biên (Invalid / Clamped) | Giá trị tại biên (Valid Boundary) | Giá trị trên biên (Invalid / Finding) | Kỳ vọng thực tế theo Code | Mã TC phủ |
|---|---|---|---|---|---|
| **BVA-01: Độ dài `title`**<br>(`EventUpsert`: `@NotBlank @Size(min=3, max=200)`; `EventFormPage`: `title.trim().length < 3`; DB `varchar(200)`) | `0` (`""`), `"   "`, `2` (`"AB"`), `" a "` (FE trim còn 1) | `3` (`"AI1"`), `200` (`"A".repeat(200)`) | `201` (`"A".repeat(201)`) | • `0`/`"   "`/`2`: FE chặn (`"Tiêu đề sự kiện phải từ 3 ký tự trở lên."`); BE trả `400 VALIDATION_FAILED`.<br>• `" a "`: FE chặn sau `.trim()`; BE `@Size` đếm cả khoảng trắng (length 3) nên cho qua `201` nếu gọi API trực tiếp.<br>• `3` & `200`: Hợp lệ (`201`).<br>• `201`: FE không chặn ở client, gửi lên BE trả `400 VALIDATION_FAILED`. | `TC-EVT-005`, `006`, `007`, `TC-EVT-WB-03`, `WB-17` |
| **BVA-02: Độ dài `location`**<br>(`EventUpsert`: `@NotBlank @Size(max=300)`; DB `varchar(300)`) | `0` (`""`), `"   "` | `1` (`"A"`), `300` (`"L".repeat(300)`) | `301` (`"L".repeat(301)`) | • `0`/`"   "`: FE báo `"Vui lòng nhập địa điểm tổ chức."`; BE trả `400`.<br>• `1` & `300`: Hợp lệ (`201`, không có giới hạn `min`).<br>• `301`: BE trả `400 VALIDATION_FAILED`. | `TC-EVT-008`, `029`, `TC-EVT-WB-03`, `WB-17` |
| **BVA-03: Độ dài `activityType`**<br>(`EventUpsert`: chỉ `@NotBlank`; DB `varchar(50)`) | `0` (`""`), `"   "` | `1` (`"X"`), `50` (`"T".repeat(50)`) | `51` (`"T".repeat(51)`) | • `0`/`"   "`: BE trả `400 VALIDATION_FAILED`.<br>• `1` & `50`: Hợp lệ (`201`).<br>• `51` *(White-box Defect)*: Thiếu `@Size(max=50)` trên `EventUpsert` → qua `@Valid`, chạm DB `varchar(50)` ném `DataIntegrityViolationException` → `500 INTERNAL_ERROR`. | `TC-EVT-013`, `029`, `TC-EVT-WB-03` |

| **BVA-08: Biên `registrationDeadline` vs `attendanceCloseAt`**<br>(`EventValidator`: `registrationDeadline.isAfter(attendanceCloseAt)`) | `deadline = close - 1s` | `deadline == close` (**Hợp lệ** theo `<=`) | `deadline = close + 1s` (**Invalid**) | • `deadline < close` và `deadline == close`: `isAfter` là `false` → **Chấp nhận (`201`)**.<br>• `deadline > close`: BE trả `400 VALIDATION_FAILED` (FE không chặn trước ở client). | `TC-EVT-011`, `029`, `TC-EVT-WB-01` |

| **BVA-10: Biên số `version` & mặc định `Event`**<br>(`EventService.update`: `upsert.version() != null && !equals`; `Event`: `qrRotationSeconds > 0`, `qrGraceSeconds >= 0`) | `version = -1` (sai lệch); `qrRotationSeconds = 0`; `qrGraceSeconds = -1` | `version = 0` (khớp v0); `qrRotationSeconds = 1` (BE) / `5..120` (DB); `qrGraceSeconds = 0` (`0..10` DB) | `version = 1` khi DB = `0` | • `version` khác DB (`0` vs `1`, hoặc `1` vs `0`): `409 VERSION_CONFLICT`.<br>• `Event` constructor: `qrRotationSeconds <= 0` → `10`; `qrGraceSeconds < 0` → `3` (`0` giữ nguyên `0`). | `TC-EVT-016`, `017`, `TC-EVT-WB-03`, `WB-07`, `WB-15` |
