### 2.2. Phân tích giá trị biên (Boundary Value Analysis — BVA)

| Biến / Tham số & Ràng buộc trong Mã nguồn | Giá trị dưới biên | Giá trị tại biên | Giá trị trên biên | Kỳ vọng thực tế theo Code | Mã TC phủ |
|---|---|---|---|---|---|
| **BVA-01: Phân trang `page`, `size` & Ngưỡng UI `size = 20`**<br>(`EventController`: `@PageableDefault(size = 20)`; `EventsPage.tsx` L37) | `page = -1`;<br>`size = 0` | `page = 0`, `page = totalPages - 1`;<br>`size = 1`, `size = 20` | `page = totalPages` (trang rỗng);<br>`totalElements = 21` (khi UI `size = 20`) | • `page = -1` / `size = 0`: Spring Data chuẩn hóa thành `page = 0` / `size = 20` (`200 OK`).<br>• `page = 0..totalPages-1`, `size = 1..20`: cắt đúng lát dữ liệu, không trùng giữa các trang.<br>• `page >= totalPages`: trả `200 OK` với `content: []`, `last: true`, `empty: true`.<br>• Khi `totalElements = 21`: API trả `totalPages = 2` (`size = 20`), nhưng UI `EventsPage` chỉ hiện 20 mục đầu do thiếu phân trang. | `TC-4.3-07`, `23`, `TC-4.3-WB-01`, `WB-08` |
| **BVA-02: Biên từ khóa `q` & Bộ đếm Debounce (`350ms`)**<br>(`EventsPage.tsx` L28-L33; `EventRepository` L19, L27) | `q = null` / `""` (`0` ký tự);<br>`t = 349ms` sau khi gõ | `q = " "` (`1` dấu cách), `q = "a"` (`1` ký tự);<br>`t = 350ms` | `q = "   "` (`3` dấu cách), `q = "%"`;<br>`t > 350ms` | • `q = ""`: FE lược bỏ param `q`; BE với `q = null` hoặc `""` trả toàn bộ trong phạm vi.<br>• `q = " "` / `"   "`: FE vẫn gửi `?q=...`; BE không trim nên tìm chuỗi khoảng trắng.<br>• `t = 349ms`: timer chưa chạy (nếu gõ tiếp sẽ `clearTimeout` hủy call cũ); `t = 350ms`: gửi duy nhất 1 `fetchEvents`. | `TC-4.3-05`, `06`, `23`, `TC-4.3-WB-05`, `WB-08` |
| **BVA-03: Biên `remainingQuota` & Thanh tiến trình**<br>(`EventService`: `Math.max(0, quotaTotal - registeredCount)`; `EventsPage.tsx` L131-L141) | `registeredCount = 0` (`0%`);<br>`registeredCount = quotaTotal - 1` (`remaining = 1`) | `registeredCount == quotaTotal` (`remaining = 0`, `100%`) | `registeredCount > quotaTotal` (vd `12/10`);<br>`quotaTotal = 0` (mock FE) | • `0` & `quotaTotal - 1`: `remainingQuota >= 1`, bar `bg-blue-600`, `registrationOpen = true` (nếu còn hạn & `PUBLISHED`).<br>• `== quotaTotal`: `remainingQuota = 0`, `100%`, bar `bg-amber-500`, `registrationOpen = false`, footer `"Đã đóng đăng ký"`.<br>• `12/10`: BE trả `remainingQuota = 0`; FE bar `width: 100%` nhưng text hiển thị `120%`.<br>• `quotaTotal = 0` (mock FE): chia 0 ra `NaN%`. | `TC-4.3-09`, `10`, `TC-4.3-WB-04`, `WB-10` |
