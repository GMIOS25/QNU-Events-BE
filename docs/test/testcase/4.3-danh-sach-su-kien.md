## 1. Điều kiện chuẩn bị môi trường & Dữ liệu mẫu

1. **Môi trường chạy:**
   - Database: PostgreSQL 17 đã chạy Flyway migration `V1__sprint1_core_schema.sql`.
   - Backend: Spring Boot chạy ở profile `dev` hoặc `demo` (mặc định `http://localhost:8080`).
   - Frontend: React + Vite chạy tại `http://localhost:5173` (múi giờ hiển thị `Asia/Ho_Chi_Minh`).
   - Công cụ hỗ trợ kiểm thử API (với các ca kiểm thử trực tiếp endpoint): Postman / Swagger UI (`/swagger-ui/index.html`) / DevTools Network.
2. **Tài khoản mẫu (`DemoDataSeeder`, mật khẩu mặc định `Demo@12345`):**
   - `owner01` — Vai trò `EVENT_OWNER` (Ban tổ chức 1).
   - `owner02` — Vai trò `EVENT_OWNER` (Ban tổ chức 2).
   - `sv001` — Vai trò `STUDENT`, thuộc lớp `K49CNTT1`.
   - `sv002` — Vai trò `STUDENT`, thuộc lớp `K49CNTT1`.
   - `sv003` — Vai trò `STUDENT`, thuộc lớp `K49CNTT2`.
   - `admin01` — Vai trò `SYSTEM_ADMIN`.
3. **Dữ liệu sự kiện chuẩn bị sẵn trước khi chạy bộ test:**
   - `EVT-PUB-K49-1`: Sự kiện do `owner01` tạo, gán lớp `K49CNTT1`, trạng thái `PUBLISHED`, tiêu đề `"Hội thảo Ứng dụng AI & Khởi nghiệp Công nghệ 2026"`, `quotaTotal = 2`, chưa có người đăng ký, còn hạn đăng ký, đang trong cửa sổ điểm danh.
