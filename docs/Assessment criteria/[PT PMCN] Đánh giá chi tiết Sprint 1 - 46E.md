# THỐNG KÊ KẾT QUẢ SPRINT 1 - 46E

## 1. Quy định & Công thức tính điểm

1. **Công thức Điểm quy đổi (Cột L):**
   $$\text{Điểm quy đổi (L)} = E + \min(F \times 0.2,\, E) + \frac{G}{2} + \min(H \times 0.1 + I \times 0.3 + J \times 0.05,\, G)$$
   *Trong đó:*
   - **Unit tests ($F$):** $0.2$ điểm / test (cộng tối đa bằng điểm code $E$)
   - **Điểm test cơ bản:** $\frac{G}{2}$
   - **Test case manual ($H$):** $0.1$ điểm / test case
   - **Test case automation ($I$):** $0.3$ điểm / test case
   - **Mỗi bug phát hiện ($J$):** $0.05$ điểm / bug
   *(Tổng phần cộng thêm từ test case & bug tối đa bằng điểm test $G$)*

2. **Điểm cuối (Cột T):** Được tính tương ứng theo điểm đóng góp của mỗi thành viên (sau khi được xử lý nén dựa trên $a^p$, Max, Mean...).
3. **Scrum Master (Cột D):** Được cộng thêm $+0.5$ điểm.
4. **Lưu ý:** Nhóm nhập chính xác làm cơ sở GV vấn đáp, xác minh và đánh giá từng thành viên. Nếu có sự không trung thực, sẽ bị trừ điểm cả nhóm.
